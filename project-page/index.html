Abstract

Building an embodied foundation model touches a long chain of ideas: transformer backbones, self-supervised visual pre-training, vision–language alignment, sparse mixture-of-experts scaling, action representations for robot control, and the systems techniques that make any of it trainable and deployable.

This survey organises that chain as one practitioner's map, distilled from the Halo Neural Insights knowledge base, and links each stage to an open reference implementation. It groups self-supervised methods by how they avoid collapse, makes the VLA design choices in π0.5 and SmolVLA explicit (FAST tokens vs flow-matching experts, knowledge insulation, System 1/2, real-time chunking), and ends with open questions the ecosystem is set up to answer. It reports no new experiments.

Highlights

Perception

ViT, DeiT, Swin, ResNet, ConvNeXt; DETR and Deformable DETR; BEVDet and BEVFormer; homographies and RANSAC.

Self-supervision

Contrastive, distillation, redundancy reduction, masked modelling and JEPA, organised by anti-collapse mechanism.

VLMs → VLAs

CLIP/SigLIP → LLaVA-style projection → RT-2, OpenVLA, π0, π0.5, SmolVLA and EO-1.

π0.5 design space

FAST (DCT + BPE) vs flow matching, knowledge insulation, System 1/System 2, real-time chunking.

MoE

Sparse gating → Switch → Mixtral → DeepSeekMoE shared experts → DeepSeek-V3.

Efficiency

FlashAttention, mixed precision, ZeRO, pipeline parallelism, pruning, PTQ and QAT.

Architecture

The repositories

Hale-VLA

From-scratch VLA: ViT + MoE decoder with <image>/<state>/<action> tokens. 355.9M params. code

HALE-WAM

World-action model: VLA + flow-matching actions + DiT future-frame prediction. 176.3M params. code

Hale-VLM

SigLIP + MLP + LoRA on Qwen3-8B / R1-Distill-7B, with SmolVLM/SmolVLA data registries. code

Halo-VLM

Three VLM paths in one library: LoRA on 8B LLMs, a from-scratch ViT-MoE model and a CLIP baseline. code

HaleBlocks

Shared components, strict configs, registries, trainer and SmolLM2/VLM data. 114 tests. code

HaloBlocks

pip-installable composable blocks: 24 attention blocks, MoE and a builder. 71 tests. code

Hale-LLM

AR vs masked diffusion vs block diffusion vs flow matching on one backbone. code

Hale-Token

Rust MoE inference on Apple Silicon: experts tiered across unified memory and SSD. code

Each repository has an arXiv-style paper, a GitHub Pages project page, Mermaid architecture diagrams, a blog post and Claude Code skills.
